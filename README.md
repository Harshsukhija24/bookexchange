# Book Exchange Platform

A full-stack web application that connects book owners with book seekers, allowing them to exchange or rent books.

## Features

- User Profiles (Owners + Seekers)
- Book Listings
- Basic Authentication
- Search and Filter functionality
- Responsive Design

## Tech Stack

- Frontend: Vite, React, Tailwind CSS
- Backend: Node.js, Express.js
- Data Storage: In-memory storage
- Development Tools: Cursor AI Assistant

## Project Structure

```
bookexchange/
├── frontend/          # React frontend application
└── backend/           # Express.js backend server
```

## Getting Started

### Frontend Setup
1. Navigate to frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start development server:
   ```bash
   npm run dev
   ```

### Backend Setup
1. Navigate to backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   node server.js
   ```
